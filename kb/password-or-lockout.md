## Steps
1. Do NOT reset or unlock anything. Help-desk resets are a common social-engineering target.
2. If the company has self-service password reset turned on, the caller can use the 'Can't access your account' link on the sign-in page. Only mention this if you know their company uses it; otherwise do not promise it.
3. Create an access ticket. A technician will call back and verify identity before any change.

## Escalate if
Always a ticket for a technician. Raise priority if the caller is a VIP or work is fully stopped; priority is set by the system.
