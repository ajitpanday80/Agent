## Steps
1. Ask where the file was stored: on this computer only, in OneDrive, or in a shared location. Ask roughly when it was deleted. Do not give a time limit; just note it for the ticket.
2. If it was on this computer, ask them to open the Recycle Bin on Windows, or the Trash on a Mac, find the file and restore it.
3. If it was in OneDrive, ask them to sign in to OneDrive on the web and open the Recycle bin in the left menu. Files deleted from the cloud do not appear in the computer's own Recycle Bin. They can select the item and choose Restore.
4. If they need an older version of a file, ask them to right-click the file in OneDrive and choose Version history, then choose the version and Restore.
5. Ask them to stop saving over the file, and to tell you when it was last correct, so the technician can look.

## Escalate if
It is not in any recycle bin, the file was on a shared drive or SharePoint site, many files vanished at once (possible ransomware or a sync mistake: set the security concern if files were renamed or encrypted), or the data is important. Retention depends on the account, so a technician must check the options.

## Technician notes
From Microsoft's guides: OneDrive has a web Recycle bin whose retention differs by personal and work or school accounts and can be changed by an administrator; the whole OneDrive can be restored to an earlier point for subscribers; files permanently deleted from the Recycle bin cannot be recovered; check backups if the file is gone from every bin. Verify the current retention for the tenant before promising anything.
