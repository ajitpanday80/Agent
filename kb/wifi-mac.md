## Steps
1. First find the scope: ask whether other devices, such as a phone, can use the same Wi-Fi, and whether anyone else in the office has the problem.
2. Ask the caller to check Wi-Fi is turned on in the menu bar, that they are within range, and that they are choosing the right network. If asked for the password, they must type it themselves; never read it out.
3. Ask them to look in the Wi-Fi menu for a Wi-Fi Recommendations item. If it appears, the Mac has found a problem and suggests a fix they can follow.
4. Restart the Mac. This lets it get a fresh address from the router.
5. If other devices are also offline, the problem is the router or the internet provider.
6. Ask them to restart the modem and router only if nobody is in the middle of important work, because it disconnects everyone. Unplug for about two minutes, plug back in and wait a few minutes.
7. Ask whether they installed VPN or security software recently, since software that watches network traffic can block internet access.
8. As a test, ask them to try another network, such as a phone hotspot. If that works, the original network is the problem.

## Escalate if
Several devices or several people are offline after the router restart, or only this Mac fails on every network. Set scope to several users or whole company when more than one person is affected.

## Technician notes
From Apple's guides: check the Mac date and time are correct; hold Option and click the Wi-Fi menu, then open Wireless Diagnostics; install router firmware updates; check VPN and network-monitoring software. Do not walk a non-technical caller through Wireless Diagnostics.
