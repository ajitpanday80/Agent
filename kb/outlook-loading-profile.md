## Steps
1. Close Outlook completely, then open it again. If it will not close, end Outlook in Task Manager.
2. Hold the Control key while opening Outlook, or run 'outlook.exe /safe'. This starts Outlook in safe mode, which turns off add-ins.
3. If safe mode works, an add-in is the likely cause. Create a ticket so a technician can find it. Do not remove add-ins by phone; disabling is safer than removing.

## Escalate if
Still failing in safe mode, or the caller sees a data file or profile corruption message. A technician may need to repair the data file; do not walk the caller through repair tools.
