## Steps
1. First ask them not to close or save over anything else yet. Ask whether the app is still open, or crashed, or they clicked Don't Save.
2. If the app crashed, ask them to open it again. Word and Excel look for recovered files when they start, and a Document Recovery pane may appear. Ask them to save the recovered file under a new name.
3. If the file was never saved, ask them to open Word or Excel, go to File, Info, Manage Document, and choose Recover Unsaved Documents, or Recover Unsaved Workbooks in Excel. If a file appears, ask them to open it and save it right away.
4. If the file was saved earlier and they closed without saving, ask them to open the file and go to File, Info, and look for a version marked as closed without saving. They can choose Restore.
5. Ask them to check the Recycle Bin and OneDrive if the file may have been deleted.

## Escalate if
Nothing is found. If they clicked Don't Save on a file that was never saved, the recovery copy may have been deleted. A technician can check backups and OneDrive version history. A file that will not open or says it is corrupted needs a technician; do not ask the caller to repair it by phone.

## Technician notes
From Microsoft's guides: AutoRecover locations on Windows include the Word folder under AppData Roaming and the UnsavedFiles folder under AppData Local; search for .asd and temporary files; use Open and Repair (File, Open, Browse, arrow beside Open) for damaged files; on a Mac, Office recovery files are in the app's folder reached via Go to Folder in Finder. Recommend turning on AutoRecover under File, Options, Save, with a short save interval.
