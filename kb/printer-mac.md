## Steps
1. Ask the caller to check that the printer is on, shows no error lights, has paper and ink or toner, and that any cable is firmly connected. A network printer must be on the same network as the Mac.
2. Ask them to open Printers and Scanners in System Settings, open the printer's queue, and click Resume if the printer shows as paused.
3. If a job is stuck with an error, ask them to select that job and delete it, then try printing one page again.
4. Ask them to try printing from another app, such as TextEdit. If it works there, the problem is the first app.
5. Turn the printer off, wait about thirty seconds, turn it back on, and try again.

## Escalate if
Still not printing after these steps, or several people cannot print (possible print server or network problem).

## Technician notes
From Apple's guide: update the printer software from the manufacturer; under the printer's Options and Supplies, turn off Print Dialog Extensions to use generic printer features; delete the printer and add it again; resetting the printing system is the last resort because it removes all printers, completed-job information and presets from this Mac. Never reset the printing system by phone.
