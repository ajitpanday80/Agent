## Steps
1. Check the printer is on, has no error or paper jam, and is on the same network as the computer.
2. Turn the printer off, unplug it for about thirty seconds, plug it back in and wait for it to be ready.
3. On the computer, open the print queue and make sure 'Pause printing' and 'Use printer offline' are not ticked, then cancel any stuck jobs.
4. Restart the computer and try one print.

## Escalate if
Still offline after these steps, or several people cannot print (possible print server or network issue). Technician handles spooler service restart, re-adding the printer and drivers.
